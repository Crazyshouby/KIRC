WhatsApp
Client non officiel : WhatsApp n'autorise pas les clients tiers, et un compte qui en utilise un peut être suspendu. KIRC se lie à votre compte comme un appareil de plus (WhatsApp, Réglages, Appareils connectés). Après « Connecter », un code s'affiche dans la fenêtre des messages : scannez-le avec le téléphone.
Pour délier l'appareil : tapez /logout dans la fenêtre des messages, ou retirez-le depuis le téléphone. Supprimer ce compte efface la session de KIRC mais ne délie pas l'appareil.
